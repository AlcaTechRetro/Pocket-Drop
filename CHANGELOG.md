# Changelog

## 1.0 (2026-11-23)

First public release.

- One-button downloads from your own Google Drive folders
- 22 consoles, NES to PSP, each with its own source and `ROMS` folder
- `ROMS` folders created automatically on first start
- Up to 4 parallel connections, with a temporary CPU and Wi-Fi speed boost
- MD5 check on every download, and auto-unzip
- Failed or stopped downloads are deleted automatically (no half-written files)
- Clear on-screen messages for Google errors (bad key, folder not shared, download limit)
- Links set on the PC (`drive_links.ini`) or on the device (**X**)
- Logs with the API key hidden, and the previous session kept in `log-previous.txt`
- LÖVE 11.4 engine bundled, with a self-check on every launch
- New icon that matches the muOS Applications list
